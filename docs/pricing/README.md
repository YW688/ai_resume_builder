### 2.2 价格带结论

- **模板/排版类会员**：¥18–29.9/月，年费 ¥80–100，终身 ¥96–99.9 —— 卖的是「模板 + 导出」。
- **AI 原生工具**：¥25–29/短期（7 天/月），普遍主打「一次购买、不自动续费」。
- **人工代写**：¥30–300/份，是我们最强的价格锚点（也是我们 0 元免费额度的对比对象）。
- **我们的位置**：¥9.9–69 覆盖「一个求职周期」，折合 **¥1.15–1.65/份简历**（一份 = 2 点），比人工代写低 1–2 个数量级，比会员制更短、更轻、决策成本更低。
- **自由侧威慑**：BOSS/智联对求职者免费，意味着我们**不能靠“能做简历”收费**，只能靠“更快、更好、按 JD 定制”收费 —— 这决定了每日免费额度必须足够让用户体验到差别，又不足以完成批量投递。

### 2.3 与旧模式（¥19/30 天不限）的对比

| 维度 | 旧模式 | 新模式 |
|---|---|---|
| 价格 | ¥19 / 30 天 | ¥9.9 / ¥29.9 / ¥69（按需） |
| 重度用户成本 | 假设 30 天内用 120 点 → token ¥0.81 | 同 120 点 = ¥0.81（冲刺包） |
| 支付手续费 | ¥0.48 | ¥0.30 / ¥0.70 / ¥1.48 |
| 毛利率（重度用户） | **93.2%** | **96.2–96.7%** |
| 客单价 | ¥19 | **¥22.81（+20%）** |

> 新模式在**客单价、毛利率、投诉风险**三方面同时优于旧模式，代价是收入确认更依赖「用户持续回来买」，需要运营触达。

## 4. 计费规则设计理由

### 4.1 为什么「整份 2 点、单段 1 点」

| 维度 | 说明 |
|---|---|
| 成本对齐 | 整份调用 token 成本是单段的 4.7 倍，但只收 2 倍点数 —— 刻意让「整份」看起来更划算，鼓励用户一次生成完整简历（Aha moment 更快）。 |
| 感知公平 | 用户能理解「整份=2、单段=1」的倍数关系；比按 token 计费（用户无法感知）更容易接受。 |
| 高频入口 | 单段润色 1 点是高频动作，低门槛让用户反复使用，形成「点数在减少」的心智，推动复购。 |
| 定价锚点 | 2 点 = 一份简历 = ¥1.15–1.65，用户会与「人工代写 30–300 元」对比，感知价值极高。 |

### 4.2 为什么每日免费 5 点

| 理由 | 说明 |
|---|---|
| 完整体验闭环 | 5 点 = 1 次整份生成（2 点）+ 3 次单段润色（3 点），新用户当天就能做出一份像样的简历，零门槛验证价值。 |
| 保留付费动机 | 投 10 个岗位需要约 20 点（10 份简历 × 2 点），免费额度**一天内做不完**；跨天积攒又会因「不累积」而无法形成批量能力 → 想批量投递就必须付费。 |
| 与竞品差异化 | 竞品普遍「免费不可下载/加水印」，我们 PDF 导出 0 点且不限，直接打穿免费侧。 |
| 心理账户 | 「每天 5 点」比「每月 150 点」感知更稀缺（每日清零），制造适度紧迫感。 |
| 风险 | 见 §8 敏感度与 §10.3 限流 —— 5 点/天理论可 0 元消耗 150 点/月，必须靠限流守住。 |

### 4.3 为什么三档套餐（¥9.9 / ¥29.9 / ¥69）

| 套餐 | 定位 | 元/点 | 心理作用 |
|---|---|---|---|
| 体验包 ¥9.9 / 12 点 / 90 天 | 引流、降低首单摩擦 | **0.825** | 「不到一杯奶茶」，把首次付费门槛压到最低 |
| 求职包 ¥29.9 / 45 点 / 180 天 | **主推**（标「最划算」） | **0.664**（−20%） | 价格锚点：比体验包便宜 20%，覆盖一个完整求职周期（约 22 份简历） |
| 冲刺包 ¥69 / 120 点 / 365 天 | 提升客单价与 ARPP | **0.575**（再 −13%） | 「一包管一年」，卖给校招/多轮面试人群，拉高 LTV |

- 阶梯折扣设计为 **−20% / −13%**：让 ¥29.9 显得是「最划算」的自然选择，又给 ¥69 留出升级理由。
- 三档都**不自动续费**（一次性购买）：符合国内用户对自动扣款的强抵触（投诉高发），也符合爱发电**无法自动扣款**的现实；代价是续费率低，需要靠到期提醒 + 内容触达补。

### 4.4 为什么有效期 90 / 180 / 365 天

| 理由 | 说明 |
|---|---|
| 匹配求职周期 | 校招/社招单次求职周期约 1–3 个月；90 天体验包正好覆盖一次。 |
| 减轻长期履约负债 | 点数过期后未消耗部分转为收入，避免长期挂账。 |
| 制造合理紧迫感 | 「90 天有效」比「永久有效」更能促使用户尽快使用（也更快暴露价值）。 |
| 合规风险 | ⚠️ 若被认定为「单用途商业预付卡」，**记名卡不得设有效期** —— 见 §11.2，需以退款/延期机制兜底。 |

### 4.5 点数定价心理学与锚点

1. **点数而非现金**：消耗「2 点」比消耗「¥1.65」痛感低，降低使用时的心理摩擦，反而提升总消耗。
2. **锚点组合**：¥29.9（主推）×「22 份简历」→ 单份 ¥1.33，对比人工代写 ¥30–300，形成巨大价值差。
3. **免费额度锚**：每日 5 点的「官方定价感」≈ 体验包单价，让用户觉得「白拿 ¥4」，提升好感与分享意愿。

## 11. 合规与风险

### 11.1 ICP 备案与经营性许可（**高风险**）

- 依据《互联网信息服务管理办法》（2024-12-06 修订）第三条、第四条、第七条：**通过互联网向上网用户有偿提供信息或网页制作等服务**属于「经营性互联网信息服务」，须取得**增值电信业务经营许可证（ICP 经营许可证）**；仅办理非经营性 ICP 备案**不能覆盖收费场景**。
- 罚则（第十九条）：未取得许可擅自经营，没收违法所得并处违法所得 3–5 倍罚款；无违法所得或不足 5 万元的，处 **10 万–100 万元**罚款，情节严重责令关闭网站。
- **建议**：上线收费前，以公司主体申请 ICP 经营许可证（省内经营，通常要求注册资本 ≥100 万元、社保人员等，具体以各省通信管理局要求为准 —— **待核实**）；个体户阶段可先以面包多Pay/爱发电的「平台代收」形态降低直接风险，但这不构成合规豁免。
- 来源：[《互联网信息服务管理办法》](http://xzfg.moj.gov.cn/front/law/detail?LawID=1756)

### 11.2 预付费点数是否构成「单用途商业预付卡」（**中风险**）

- 《单用途商业预付卡管理办法（试行）》第二条：适用范围为**零售业、住宿和餐饮业、居民服务业的企业法人**；单用途卡指「仅限于在本企业兑付货物或服务的预付凭证」，含虚拟卡。
- 第十九条：**记名卡不得设有效期；不记名卡有效期不得少于 3 年**；第二十一条要求提供退卡服务。
- 我们的点数：记名（绑定账号）、仅限本平台、预付购买 —— 形态上接近「虚拟单用途卡」，但**行业不在办法列举的三类**，且点数更接近「服务计量单位/积分」而非「兑付凭证」。
- **风险点**：90/180/365 天有效期若被认定为单用途卡，则与「记名卡不得设有效期」冲突。
- **建议**：
  1. 用户协议明确「点数为 AI 服务计量单位，非预付卡、不可转让、不可兑现、不可提现」；
  2. 提供**未消耗点数按比例退款**通道（7 日内无理由 / 未使用部分可退）；
  3. 到期前 7 天提醒，并提供一次免费延期；
  4. 若规模做大，主动咨询属地商务部门，或把有效期延长至 3 年以彻底规避。
- 来源：[商务部令第9号](https://www.gov.cn/zhengce/2012-09/21/content_5712346.htm)

### 11.3 退款规则

- 虚拟服务已消耗部分不退；**未消耗点数 7 日内可退**（按实付金额 × 未用比例，扣支付手续费）。
- 明确「过期不退但可申请一次延期」；在购买页、支付前弹窗、协议三处显著提示。
- 退款率对利润影响可控：0%→15% 时基准利润从 +¥541 到 +¥187（仍为正），但会显著拉低净利率，需监控。

- 调用 DeepSeek API 属于**委托处理**：需在隐私政策中披露第三方处理者、处理目的与数据范围，并确认 API 方不留存/不用于训练（以 DeepSeek 服务条款为准，**待核实**）。
- 建议：传输 HTTPS + 存储加密、日志脱敏（不落手机号/身份证）、默认不公开简历、注销即删除。
- 来源：[《个人信息保护法》](http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)

### 11.5 税务

- 小规模纳税人月销售额 ≤10 万元**免征增值税**（执行至 2027-12-31），我们的量级（月收入 <¥1.5 万）适用；超过后按 1% 征收（3% 减按 1%）。
- 所得税：小型微利企业实际税负按 5% 估算（模型已按 5% 计提）；个体户经营所得 5%–35% 超额累进，建议注册个体户/小微公司并申请核定征收（**待核实属地政策**）。
- 来源：[财政部 税务总局公告2023年第19号](https://www.gov.cn/zhengce/zhengceku/202308/content_6896287.htm)

### 11.6 DeepSeek 限流 / 欠费 / 调价降级（**中风险**）

- 并发限制：flash 2,500、pro 500；高峰期（工作日 9–12、14–18 点）可能排队或 429。
- 欠费即停服：需余额告警（<¥50 提醒 + 自动充值）+ 降级策略（pro → flash）+ 排队重试 + 本地模板兜底（AI 不可用时仍可编辑/导出 PDF）。
- 官方保留调价权；模型名与价格可能变动，需把「模型单价」做成配置项（本脚本即为此设计）。
- 来源：[DeepSeek 模型&价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) / [限速与隔离](https://api-docs.deepseek.com/zh-cn/quick_start/rate_limit)

### 11.7 其他风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 支付渠道二清/跑路（面包多Pay/爱发电） | 资金安全、用户信任 | 优先官方直连；分散渠道；对账 |
| 爱发电 6% 费率 | 毛利率 −3.0~3.7pp | 仅作兜底，不做主渠道 |
| AI 生成虚假经历 | 用户投诉/平台责任 | 协议禁止 + 生成内容提示「请核实真实性」 |

| 竞品价格战 | ARPP 下滑 | 不跟进降价，用赠点与增值功能竞争 |

## 12. 结论：推荐定价方案

### 12.1 明确推荐

| 项目 | 推荐值 |
|---|---|
| 体验包 | **¥9.9 / 12 点 / 90 天**（保留） |
| 求职包 | **¥29.9 / 45 点 / 180 天**（保留，主推，目标占比 55–60%） |
| 冲刺包 | **¥69 / 120 点 / 365 天**（保留） |
| 每日免费额度 | **5 点/天**（保留，但必须加限流：单账号 60 次/日、整份生成 2 次/日） |
| 目标毛利率 | **≥90%（红线）／实际 96.5%（目标）** |
| 目标净利率 | 规模 ≥3,000 MAU 时 **≥18%**（3,000 MAU / 3% 实测 19.5%） |
| 支付渠道 | 面包多Pay 过渡 → 2026 Q4 前完成个体户/企业 + 微信/支付宝直连（0.6%） |
| 保本目标 | **2,000 MAU @3% 转化**（或 768 MAU @5%） |
| 12 个月经营目标 | MAU 3,000 / 转化 3% / 月税前 ¥470；冲刺目标 MAU 10,000 / 5% / 月税前 ¥5,871 |

### 12.2 为什么不是「更便宜」或「更贵」

- **不更便宜**：token 成本仅占客单价 1.02%，降价 30% 只会把毛利从 96.5% 压到约 96%，却几乎无法把转化率从 3% 拉到 5%（敏感度显示：要 +¥1,082 利润，需要转化率翻倍，而不是降价）。
- **不更贵**：¥29.9 已高于超级简历/职徒月费（¥18–19.9），但仅为人工代写（¥30–300/份）的 1/1–1/10；再高会打击「一次性买断」的价格优势，且与 AI 简历姬 ¥29 正面撞车。
- **真正杠杆**：把求职包占比从 35% 提到 60%（ARPP 从 ¥22.81 → ¥27+）、把 CAC 从 ¥10 降到 ¥5、把免费额度限流做到位。

### 12.3 上线前 Checklist

- [ ] 支付通道：面包多Pay 商户审核通过，微信/支付宝可用，回调与对账打通
- [ ] 点数账本：每日免费额度 00:00（Asia/Shanghai）重置、不累积；先扣免费再扣余额；有效期精确到秒
- [ ] 限流：账号/IP/设备三级 + 整份生成日限 2 次 + 手机验证
- [ ] 协议：点数非预付卡、有效期、退款、过期延期、AI 生成内容免责
- [ ] 合规：ICP 备案（先）+ ICP 经营许可证（收费前，公司主体）；隐私政策含第三方 API 披露
- [ ] 运营：到期提醒、余额告警、DeepSeek 欠费告警与降级开关
- [ ] 埋点：转化漏斗（注册→首次 AI→额度用尽→购买页→支付）、退款率、CAC 分渠道

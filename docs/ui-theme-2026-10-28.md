# 界面改版记录 · 三主题 + 全局毛玻璃 + 顶栏点数胶囊（2026-10-28）

> 本次改版针对用户反馈：①侧栏姓名与邮箱挤在一行、模糊；②账户设置在侧栏最底部、点开被裁切；
> ③侧栏大片空白、页面不够优雅；④点数卡占侧栏一大块、应精简到顶栏消息旁；⑤整体配色过于商务。
>
> 约束：全局保留毛玻璃；三套主题取自用户提供的三张 palette 参考图；不新增依赖；不改认证/支付/数据库逻辑。

## 1. 主题

| id | 名称 | 气质 | 主要色 |
|---|---|---|---|
| `mist`（默认） | 晴岚 | 淡紫雾面玻璃 | `#ece9f7 / #6c4ce0 / #b7a8ff / #ffb4d4 / #1c1733` |
| `ember` | 绯雾 | 暖白纸面绯红 | `#f7eeee / #c81c38 / #fe2e4b / #161316 / #4b4a4b` |
| `midnight` | 子夜 | 深靛电光紫 | `#0b0920 / #2631ad / #7f24e7 / #2affcc / #f2f0ff` |

- 唯一来源：`app/themes.css`。用 `:root[data-theme="…"]` 覆盖 `--ui-*` 与 `--ui-glass-*` / `--ui-ambient-*`，与 `app-ui.css` 的加载顺序无关。
- 首帧：`app/layout.tsx` 的 `THEME_BOOT` 内联脚本在水合前写 `<html data-theme>`，避免闪白；`<html>` 加了 `suppressHydrationWarning`。
- 状态：`components/theme/ThemeProvider.tsx`（`useSyncExternalStore` 订阅 DOM），持久化 key `app.theme.v1`；支持多标签同步。
- 切换入口：设置 → 外观（`components/theme/ThemePicker.tsx`，三张带缩略预览的卡片）；侧栏账户菜单「切换主题」可循环切换。
- 默认固定 `mist`，不跟随系统深浅色，避免首次进入被误判成深色。

## 2. 毛玻璃系统

- Token：`--ui-glass`（侧栏/顶栏胶囊）、`--ui-glass-sheet`（主面板）、`--ui-glass-card`（卡片）、`--ui-glass-strong`（弹层/菜单/对话框）、`--ui-glass-border`、`--ui-glass-line`、`--ui-glass-highlight`、`--ui-shadow-float` / `--ui-shadow-sheet`。
- 环境光：`.app-shell::before` 用三层 `--ui-ambient-*` 径向色场，是玻璃“看得见”的底；玻璃只加在壳层/弹层/卡片，不在 panel 内叠加 backdrop-filter（性能）。
- 兜底：`@supports not (backdrop-filter)` 与 `prefers-reduced-transparency: reduce` 全部退回实色。
- A4 简历纸面与打印样式始终白纸黑字，不跟随主题。

## 3. 壳层调整

- 壳层改「浮动卡片」布局：`padding/gap: 10px`，侧栏 18px 圆角玻璃卡、主面板 18px 圆角玻璃板。

## 8. 追加（2026-10-28 深夜）：顶栏独立固定，内容区独立滚动

- 壳层改为「一屏固定」：`.app-shell { height: 100svh; overflow: hidden }`，`.app-main` 高度受控，滚动只在 `.app-sheet` 内部发生。
- 效果：顶栏（面包屑 / 搜索 / 点数胶囊 / 通知 / 头像）与左侧栏在页面内容滚动时**完全不动**；内容在玻璃面板内滚动。
- 细节：`.app-sheet` 增加 `overscroll-behavior: contain`、`scrollbar-gutter: stable` 与细滚动条样式；移动端同样固定顶栏（52px），内容在面板内滚动。
- 路由切换时手动把 `.app-sheet` 滚回顶部（Next 只管理 window 滚动）：见 `AppShell.tsx` 的 `sheetRef` effect。
- 设置页原先「把滚动让回 document」的 `:has` 补丁已删除（不再需要，sticky 子导航在面板滚动容器内正常工作）。
- 验证：滚动前/后 `topbar.top` 恒为 10（移动端 0），`window.scrollY` 恒为 0，`app-sheet.scrollTop` 324/457/700；简历卡菜单在滚动后打开不被面板裁切；路由切换后 `scrollTop` 归零。

## 9. 追加（2026-10-29 凌晨）：顶栏改成独立玻璃胶囊

- 顶栏不再是悬浮在图上的零散元素，收成一枚**独立玻璃胶囊**（46px 高、`border-radius: 999px`、`--ui-glass` 底 + 22px 模糊、内顶高光 + 浮动阴影），横向占满主列，与左侧栏卡片、下方内容面板同高对齐 —— 参考落地页 Hero 顶部的胶囊导航，但沿用工作台的 token（三套主题自动适配）。
- 胶囊内容：左侧面包屑、居中搜索（改成低对比内嵌搜索框，不再叠第二层玻璃）、右侧点数胶囊 / 通知 / 头像；移动端同款胶囊（52px），菜单、标题、搜索、点数、通知、头像全部放得下。
- 顶栏与内容面板仍互相独立（上一节的壳层固定逻辑不变）。

### 修：胶囊顶栏遮住浮层

顶栏加 `backdrop-filter` 后会成为独立层叠上下文，浮层（点数面板、通知）即使 `z-index: 75` 也会被后出现的 `.app-sheet`（同样有 backdrop-filter）压住。给 `.app-topbar` 加 `position: relative; z-index: 30`，浮层恢复显示；实测点数面板与通知弹层均为命中元素（elementFromPoint 在浮层内部）。
